# Changelog -- PINE (CatBorg Studio)

## Version 1.22.0

**Release type:** Minor Update\
**Summary:** Full A\* Pathfinding Project integration across movement
nodes and introduction of A\* Modifier control.

------------------------------------------------------------------------

### Added

-   **MoveTo**
    -   Now supports A\* Pathfinding Project via `IAstarAI` integration.
    -   Assigns destination directly to the A\* agent.
    -   Returns Success when `reachedDestination` becomes true.
-   **Chase**
    -   Continuous target-following behavior powered by A\* navigation.
    -   Updates destination dynamically while the target moves.
    -   Uses A\* path state validation (`hasPath`, `pathPending`).
-   **Flee**
    -   Reactive fleeing behavior using A\* navigation.
    -   Continuously recalculates escape direction relative to the
        threat target.
    -   Fully integrated with unified navigation architecture.
-   **Patrol**
    -   Waypoint-based movement now supports A\* navigation.
    -   Uses the same unified movement pipeline as other navigation
        systems.
-   **RandomDestination**
    -   Random roaming behavior now compatible with A\*.
    -   Ensures generated destinations are reachable before being
        accepted.
-   **Stop**
    -   Stops the active A\* agent safely.
    -   Sets `isStopped` and halts movement without breaking path state.
-   **ModifierSet**
    -   New ActionNode for modifying A\* Seeker modifiers at runtime.
    -   Supports:
        -   `FunnelModifier`
        -   `RaycastModifier`
        -   `SimpleSmoothModifier`
        -   `AdvancedSmoothModifier` (if available)
    -   Reflective access to public fields and properties.
    -   Supports override modes:
        -   New Value
        -   Change By Value
        -   Multiply By Value
    -   Can automatically add the selected modifier component if
        missing.

------------------------------------------------------------------------

### Changed

-   **Unified Navigation Architecture**
    -   Movement nodes now support:
        -   None (direct movement)
        -   Unity NavMesh
        -   Nav3D
        -   A\* Pathfinding Project
    -   Consistent state handling (`Running`, `Success`, `Failure`)
        across all navigation backends.
    -   Improved validation and failure handling when navigation systems
        are unavailable.
-   **AStarIntegrator**
    -   Reflection-based detection of:
        -   `AstarPath`
        -   `IAstarAI`
        -   `Seeker`
        -   Built-in A\* modifiers
    -   Runtime validation ensures A\* graphs are initialized before
        movement begins.
    -   Safe fallback behavior when A\* is not installed.
-   **ModifierSet Inspector**
    -   Detects whether A\* is installed.
    -   Disables UI when A\* is missing.
    -   Displays contextual warning message.
    -   Dynamically updates available fields based on selected modifier
        type.

------------------------------------------------------------------------

### Removed

-   No removals in this release.

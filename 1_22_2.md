# Changelog – PINE (CatBorg Studio)
## Version 1.22.2

**Release type:** Patch Update  
**Summary:** Performance Boost — optimized Behaviour Tree state propagation and improved Unity version compatibility.

---

### Improved

- **Behaviour Tree Execution**
  - Reduced CPU overhead by skipping repeated deactivation of unchanged inactive subtrees.
  - Introduced a shared traversal buffer prepared during tree initialization.
  - No GC allocations detected during warmed-up ticks in the tested core scenarios.

- **Sequencer / Selector / Fork / Branching**
  - Optimized state propagation when deactivating branches.
  - Preserved existing node states and `OnStart`, `OnUpdate`, and `OnStop` behavior.

---

### Changed

- **Runtime State Handling**
  - Automatic branch deactivation now uses the optimized traversal path.
  - Explicit `SetState` calls and custom overrides retain their existing behavior.
  - Serialized Behaviour Tree data remains unchanged; no asset migration is required.

---

### Fixed

- **Unity Compatibility**
  - Resolved obsolete object-search API warnings on Unity 6.4+ through conditional compilation.
  - Corrected serialization attributes on reflection caches and editor views.
  - Corrected UI Toolkit version guards while retaining legacy UXML factories for older Unity versions.

---

### Removed

- No removals in this release.
